# Single-Page CV

A clean, single-page Curriculum Vitae built with semantic HTML. This project focuses on proper document structure, SEO best practices, and accessible markup -- with styling to be addressed in a future project.

## Project Overview

This CV page showcases a professional career history including education, skills, work experience, certifications, and languages. It is built using only HTML with no CSS or JavaScript, emphasizing correct semantic structure.

## Features

- **Semantic HTML**: Uses appropriate HTML5 elements (`header`, `main`, `footer`, `section`, `article`, `nav`, `address`, `time`) for a well-structured, accessible document.
- **SEO Meta Tags**: Includes `description`, `keywords`, and `author` meta tags to improve search engine visibility.
- **Open Graph Tags**: Adds `og:title`, `og:description`, `og:type`, `og:url`, `og:image`, and `og:locale` for rich social media link previews.
- **Favicon**: A custom favicon is linked in the document head.
- **Single-Page Layout**: All CV content is presented on a single page with clearly defined sections.

## Sections

1. **Header** -- Name, job title, social links, and contact information.
2. **Professional Summary** -- A brief overview of experience and expertise.
3. **Skills** -- Organized into Programming Languages, Frameworks and Libraries, and Tools and Platforms.
4. **Work Experience** -- Three roles with company details, date ranges, and key accomplishments.
5. **Education** -- Degree, institution, and relevant coursework.
6. **Certifications** -- Professional certifications with year of completion.
7. **Languages** -- Spoken languages and proficiency levels.

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in any web browser.

No build tools, dependencies, or server setup required.
